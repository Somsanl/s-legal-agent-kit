# กฎโครงสร้างคำฟ้องแพ่งและคำร้องศาล 3 ส่วน (`thai-legal-drafting`)

## 1. โครงสร้างคำฟ้องแพ่งมาตรฐาน (กู้ยืมเงิน • ซื้อขาย • ละเมิด)

### 1.1 การจัดลำดับข้อในคำฟ้อง
1. **กรณีคู่ความทุกฝ่ายเป็นบุคคลธรรมดาและไม่มีหนังสือมอบอำนาจฟ้อง**:
   - เริ่ม `ข้อ ๑.` ด้วยเนื้อหานิติสัมพันธ์หรือเหตุละเมิดได้ทันที
2. **กรณีโจทก์หรือจำเลยเป็นนิติบุคคล หรือโจทก์มอบอำนาจให้ฟ้องคดีแทน**:
   - **`ข้อ ๑.`**: บรรยายสถานะนิติบุคคลของโจทก์ (จดทะเบียนเป็นนิติบุคคลประเภทบริษัทจำกัด เลขทะเบียน วัตถุประสงค์ที่เกี่ยวข้อง กรรมการผู้มีอำนาจกระทำการแทนตามหนังสือรับรอง เอกสารท้ายฟ้องหมายเลข ...) การมอบอำนาจช่วงให้ฟ้องคดี (ถ้ามี) และสถานะนิติบุคคลของจำเลย (ถ้าจำเลยเป็นนิติบุคคล)
   - **`ข้อ ๒.`**: บรรยายนิติสัมพันธ์ต้นเหตุแห่งมูลคดี (สัญญากู้ยืมเงิน / สัญญาซื้อขาย / เหตุละเมิด) วันเวลา สถานที่ จำนวนเงิน และหลักฐานสำคัญ
   - **`ข้อ ๓.`**: บรรยายการผิดนัด การชำระหนี้บางส่วน (ถ้ามี) การบอกกล่าวทวงถาม/บอกเลิกสัญญา และการคำนวณยอดหนี้ต้นเงินพร้อมดอกเบี้ยคิดถึงวันฟ้อง (หรือข้อย่อยค่าเสียหายในคดีละเมิด `๓.๑`, `๓.๒`, ... พร้อมวรรคสรุปยอดรวม)
   - **`ข้อ ๔.` (หรือข้อสุดท้าย)**: บรรยายว่าโจทก์ไม่มีทางอื่นใดที่จะบังคับจำเลยได้ จึงต้องนำคดีมาฟ้องต่อศาลเพื่อขอบารมีศาลเป็นที่พึ่ง
   - ปิดท้ายด้วย `ควรมิควรแล้วแต่จะโปรด` และคำขอท้ายฟ้องแยกแผ่นตามแบบพิมพ์ศาล

### 1.2 แพทเทิร์นมูลคดีแพ่งหลัก
- **คดีกู้ยืมเงิน (`Loan`)**:
  1. กู้ยืมเงินเดี่ยว / ผ่อนชำระรายเดือน
  2. กู้ยืมเงินพร้อมผู้ค้ำประกัน (ต้องตรวจหนังสือบอกกล่าวผู้ค้ำประกันภายใน 60 วันนับแต่วันที่ลูกหนี้ผิดนัดตาม ป.พ.พ. มาตรา 686)
  3. กู้ยืมเงินที่มีหนังสือรับสภาพหนี้หรือชำระหนี้บางส่วน
  4. กู้ยืมเงินพร้อมจำนองและขอให้บังคับจำนอง (ต้องตรวจหนังสือบอกกล่าวบังคับจำนองล่วงหน้าไม่น้อยกว่า 60 วันตามมาตรา 728)
- **คดีซื้อขาย (`Sale`)**:
  1. ซื้อขายสินค้าส่งมอบแล้วค้างชำระราคา (วางบิลใบแจ้งหนี้ หรือเช็คปฏิเสธการจ่ายเงิน)
  2. สัญญาจะซื้อจะขายที่ดิน/อาคาร ผู้ขายผิดสัญญา ฟ้องเลิกสัญญาเรียกเงินมัดจำ/เงินดาวน์คืนพร้อมดอกเบี้ย
  3. สัญญาจะซื้อจะขายที่ดิน ผู้ซื้อชำระครบ ฟ้องบังคับโอนกรรมสิทธิ์และถือเอาคำพิพากษาแทนการแสดงเจตนา
  4. ซื้อขายทรัพย์สินที่กรรมสิทธิ์โอนแล้ว ฟ้องเรียกทรัพย์คืนหรือใช้ราคาพร้อมค่าขาดประโยชน์รายเดือน
- **คดีละเมิด (`Tort`)**:
  1. ขับรถประมาททำให้บาดเจ็บแก่กาย/สุขภาพ หรือทรัพย์สินเสียหาย
  2. ลูกจ้างทำละเมิดในทางการที่จ้าง ฟ้องลูกจ้างและนายจ้างร่วมรับผิด (ม.425)
  3. ทำร้ายร่างกาย (อ้างรายงานประจำวันและผลคดีอาญา)
  4. ก่อสร้าง/ถมดินที่ดินข้างเคียงพังทับบ้านเสียหาย พร้อมคำขอท้ายฟ้องให้รื้อถอน
  5. บริษัทประกันภัยจ่ายค่าสินไหมทดแทนแล้วรับช่วงสิทธิฟ้องผู้ทำละเมิด (ม.880)
  - หมวดข้อย่อยค่าเสียหายที่ใช้บ่อย: ค่ารักษาพยาบาลที่ผ่านมา/ในอนาคต, ค่าทนทุกข์ทรมาน, ค่าขาดประโยชน์ทำมาหาได้, ค่าจ้างผู้ดูแล, ค่าปลงศพ, ค่าขาดไร้อุปการะ, ค่าซ่อมรถ, ค่าขาดประโยชน์จากการใช้รถ, ค่าเสื่อมราคารถ

## 2. กฎเหล็กคำร้อง คำแถลง และคำขอในชั้นศาล (3-Part Structure)

คำร้อง คำแถลง และคำขอทุกฉบับต้องมีองค์ประกอบครบ 3 ส่วนตามลำดับนี้เสมอ:

### ส่วนที่ 1: `ข้อ 1.` สถานะคดีและวันนัดปัจจุบัน (ห้ามข้ามเด็ดขาด)
- ยื่นก่อนวันนัด: `ข้อ 1. คดีนี้ ศาลได้นัด[ชี้สองสถานและสืบพยานโจทก์ / ไกล่เกลี่ย / ฟังคำพิพากษา] ในวันที่ [วัน เดือน พ.ศ.] เวลา [09.00] นาฬิกา`
- ยื่นในวันนัดพิจารณา: `ข้อ 1. คดีนี้ ศาลได้นัด[ประเภทนัด]ในวันนี้`
- ยื่นหลังมีคำพิพากษา (เช่น ขอขยายอุทธรณ์ ขอคัดถ่ายคำพิพากษา ขอออกคำบังคับ): `ข้อ 1. คดีนี้ ศาลได้มีคำพิพากษาเมื่อวันที่ [วัน เดือน พ.ศ.] ...`

### ส่วนที่ 2: `ข้อ 2.` เหตุผลและความจำเป็นแห่งคำร้อง
- บรรยายข้อเท็จจริงและเหตุขัดข้องตามความจริงโดยอ้างอิงพยานหลักฐานแนบท้ายคำร้อง (เช่น ใบรับรองแพทย์ หมายนัดศาลอื่น ทะเบียนราษฎร ผลการนำส่งหมาย)
- แยกเป็น `ข้อ 3.` เฉพาะกรณีที่มีประเด็นต่อเนื่องชัดเจน เช่น รายละเอียดคำสั่งเดิมหรือผลกระทบหากไม่ได้รับอนุญาต

### ส่วนที่ 3: คำขอท้ายคำร้อง (ไม่ใส่เลขข้อ) + บล็อกลงชื่อ 4 บรรทัด
- ย่อหน้าคำขอท้ายคำร้องห้ามใส่เลขข้อ เช่น:
  `อาศัยเหตุดังกราบเรียนข้างต้น ขอศาลได้โปรดมีคำสั่งอนุญาตให้ขยายระยะเวลายื่นคำให้การของจำเลยออกไปอีก 30 วัน นับแต่วันครบกำหนดเดิม เพื่อประโยชน์แห่งความยุติธรรมด้วย`
- บล็อกลงชื่อ 4 บรรทัดมาตรฐาน (เว้นช่องว่างหลังคำว่า `ลงชื่อ` สำหรับลายมือชื่อจริง):
  ```text
  					ควรมิควรแล้วแต่จะโปรด
  				ลงชื่อ				ทนายจำเลย ผู้ร้อง
  	คำร้องฉบับนี้ ข้าพเจ้านายสมชาย ตัวอย่าง ทนายจำเลย เป็นผู้เรียงและพิมพ์
  				ลงชื่อ				ผู้เรียงและพิมพ์
  ```

## 3. การออกเอกสารผ่าน S-Legal MCP (และเครื่องมือเสริม)

1. **ออกไฟล์ `.docx` ลงสำนวนใน S-Legal โดยตรง**:
   - เรียก `slegal_case_parties_get({ caseId })` -> `slegal_court_templates_list` -> `slegal_court_document_preview` (ส่งเนื้อหาใน `clauseOverrides`: `petitionTitle`, `clause1Body`, `petitionDetails`, `prayer1`, `signerRole`, `drafterName`, `drafterRole`) -> `slegal_court_document_generate`
2. **หากสภาพแวดล้อมมีเครื่องมือเทมเพลตคำคู่ความเสริม (เช่น SLegalTools)**:
   - ใช้คีย์จากสภาพแวดล้อมของเครื่องมือเสริมนั้นโดยห้ามพิมพ์หรือส่ง API Key ในแชตหรืออาร์กิวเมนต์คำสั่ง และตรวจสอบความถูกต้องของแม่แบบก่อนนำไปสร้างไฟล์ `.docx`
