# คู่มือการพิสูจน์อักษรภาษาไทยและมาตรฐานการสร้างไฟล์ `.docx` (`thai-legal-drafting`)

## 1. รายการตรวจพิสูจน์อักษรภาษาไทยสำหรับเอกสารกฎหมาย (`Thai Legal Proofreading`)

### 1.1 คำที่มักสะกดผิดหรือใช้ผิดความหมายในเอกสารกฎหมาย
| คำที่ผิดบ่อย | คำที่ถูกต้องตามมาตรฐานกฎหมาย | หมายเหตุ |
|---|---|---|
| `โจทย์` | **`โจทก์`** | ผู้ฟ้องคดีในศาลใช้ ก ไก่ การันต์เสมอ |
| `สิทธิ์`, `บุริมสิทธิ์`, `กรรมสิทธิ์` | **`สิทธิ`**, **`บุริมสิทธิ`**, **`กรรมสิทธิ์`** | คำว่า `สิทธิ` และ `บุริมสิทธิ` ตาม ป.พ.พ. ไม่ใส่ไม้ทัณฑฆาต ส่วน `กรรมสิทธิ์` และ `ลิขสิทธิ์` มีไม้ทัณฑฆาต |
| `อนุญาติ`, `ญาติ` | **`อนุญาต`**, **`ญาติ`** | `อนุญาต` ไม่มีสระอิ |
| `สังเกตุ`, `เหตุ` | **`สังเกต`**, **`เหตุ`** | `สังเกต` ไม่มีสระอุ |
| `คำนวน` | **`คำนวณ`** | สะกดด้วย ณ เณร |
| `ปรากฎ`, `กฏหมาย`, `กฏกระทรวง` | **`ปรากฏ`**, **`กฎหมาย`**, **`กฎกระทรวง`** | `ปรากฏ` ใช้ ด ชฎา (หยักเดียว); `กฎ` ใช้ ฎ ชฎา (สองหยัก) |
| `สถานะการณ์` | **`สถานการณ์`** | ไม่ประวิสรรชนีย์หลัง น หนู |
| `ชำระหนี`, `ลูกหนี`, `เจ้าหนี` | **`ชำระหนี้`**, **`ลูกหนี้`**, **`เจ้าหนี้`** | ตรวจวรรณยุกต์โทตกหล่นจากการพิมพ์หรือ OCR |
| `ผูกพันธ์` | **`ผูกพัน`** | ไม่มี ธ ธง การันต์ |
| `ฑูต`, `ทนายความผู้รับมอบฉันฑะ` | **`ทูต`**, **`ผู้รับมอบฉันทะ`** | ใช้ ท ทหาร |
| `นะค่ะ` | **`นะคะ`** | เอกสารทางการให้ตัดคำลงท้าย `ครับ/ค่ะ/นะคะ` ออกทั้งหมด เว้นแต่คัดลอกข้อความแชตตามพยานหลักฐาน |

### 1.2 การตรวจระดับประโยคและเนื้อหา (Meaning & Completeness Pass)
1. **ตรวจคำตกและคำซ้ำติดกัน**: เช่น พิมพ์คำเชื่อมซ้ำ (`และ และ`, `โดย โดย`), ขาดกริยาหลักของประโยค, หรือเปิดวงเล็บ/อัญประกาศแล้วลืมปิด
2. **ตรวจความตรงกันของตัวเลขและตัวอักษร**: จำนวนเงินตัวเลขกับตัวอักษรวงเล็บท้ายตัวเลข เช่น `150,000 บาท (หนึ่งแสนห้าหมื่นบาทถ้วน)` ต้องตรงกันทุกจุด รวมถึงเลขข้ออ้างอิงเอกสารท้ายฟ้อง
3. **แยกประเภทผลตรวจ 3 ระดับ**:
   - **`ผิดแน่`**: สะกดผิดชัดเจน คำซ้ำติดกัน หรือตัวเลขไม่ตรงตัวอักษร
   - **`ควรแก้`**: คำที่มีรูปสะกดถูกแต่ผิดบริบทกฎหมาย (เช่น `โจทย์` แทน `โจทก์`) เว้นแต่เป็นชื่อเฉพาะตามเอกสารต้นฉบับ
   - **`ปรับสำนวน`**: ไม่ผิดไวยากรณ์ แต่ปรับให้กระชับและเป็นภาษากฎหมายทางการมากขึ้น (ห้ามแก้ถ้อยคำในแม่แบบล็อกหรือข้อความคัดลอกตามสัญญาโดยพลการ)

## 2. มาตรฐานทางเทคนิคสำหรับการสร้างและแก้ไขไฟล์ `.docx` ภาษาไทย

Microsoft Word เข้มงวดกว่า LibreOffice ทั้งเรื่องการตัดคำภาษาไทย (Complex Script) และความถูกต้องของโครงสร้าง XML (`OOXML`)

### 2.1 ค่าเริ่มต้นฟอนต์และการจัดหน้า
- **ฟอนต์เดียวทั้งฉบับ**: `TH SarabunPSK`
- **ขนาดตัวอักษร**: `15 pt` สำหรับเนื้อหา ย่อหน้า ตาราง รายการย่อย และเลขหน้า; หัวข้อเรื่องใช้ **`15 pt ตัวหนา`** เป็นค่าเริ่มต้น
- **ขนาดกระดาษและระยะขอบ**: กระดาษ `A4` ระยะขอบมาตรฐานประมาณ `1 นิ้ว (2.54 ซม.)` เว้นแต่ใช้แม่แบบฟอร์มศาลที่มีระยะขอบเฉพาะ

### 2.2 กฎบังคับระดับ OOXML Run (`w:rPr`) เพื่อป้องกันคำฉีก/ตัดบรรทัดเพี้ยนใน Word
ทุก Run ที่มีข้อความภาษาไทยต้องตั้งค่าใน `w:rPr` ให้ครบทั้ง 4 ส่วนแบบ Idempotent (อัปเดตตัวเดิม ห้ามใส่ tag ซ้ำ):
1. **`<w:rFonts w:ascii="TH SarabunPSK" w:hAnsi="TH SarabunPSK" w:eastAsia="TH SarabunPSK" w:cs="TH SarabunPSK"/>`**
2. **`<w:cs/>`** (สำคัญมาก: หากไม่มี `<w:cs/>` Microsoft Word จะไม่มองว่าเป็นภาษาไทยแบบ Complex Script ทำให้ตัดคำท้ายบรรทัดผิดเพี้ยน)
3. **`<w:lang w:val="th-TH" w:eastAsia="th-TH" w:bidi="th-TH"/>`**
4. **`<w:noProof/>`** (คู่กับการตั้งค่าซ่อนเส้นหยักตรวจคำผิดใน `word/settings.xml`)

### 2.3 กฎการจัดหน้าแบบพิมพ์ศาล หมายเรียก คำร้อง บัญชีพยาน และข้อห้าม OOXML
- **จัดกระจายเต็มบรรทัดเนื้อหาเอกสารศาล (`thaiDistribute`)**: ย่อหน้าเนื้อหาหลักของคำร้อง คำแถลง คำขอ คำฟ้อง และคำให้การ **ต้องตั้งค่า `w:jc w:val="thaiDistribute"` (จัดกระจายเต็มบรรทัดแบบไทย) ทุกครั้ง** โดยต้องมี `<w:cs/>` และ `w:lang th-TH` ครบทุก Run เพื่อไม่ให้ช่องไฟหรือการตัดคำเพี้ยน (หลีกเลี่ยง `w:docGrid` แบบบังคับตารางตัวอักษร)
- **ชื่อคำร้องมุมซ้ายบน (`T0.R0.C0`)**: ห้ามจัดกึ่งกลาง (`center`) เด็ดขาด — ต้องตั้งค่าจัดชิดซ้าย (`w:jc w:val="left"`) เสมอ
- **แบบฟอร์มหมายศาล/หมายเรียก**: ห้ามแก้ไขโครงสร้างหรือย่อขนาดตัวอักษรของตัวแบบพิมพ์หมายศาลและข้อความคำเตือนต่าง ๆ ทุกจุด — อนุญาตให้ย่อขนาดตัวอักษรได้เฉพาะ **ด้านหลังหมายส่วนระบุรายละเอียด (เช่น รายการพยานเอกสาร)** เท่านั้น โดยคำเตือนต่าง ๆ บนหมายต้องคงขนาดเดิม
- **บัญชีพยาน (บัญชีระบุพยานเอกสาร)**: เมื่อระบุรายการเอกสารแต่ละลำดับเสร็จแล้ว **ไม่ต้องเว้นบรรทัดว่างคั่นระหว่างแต่ละลำดับ** ให้ขึ้นลำดับถัดไปต่อเนื่องได้เลย
- **ห้ามเขียนทับ XML ของ Word ด้วย `xml.etree.ElementTree` มาตรฐานของ Python** เพราะจะเปลี่ยนชื่อ Namespace Prefix และทำลาย `mc:Ignorable` จน Microsoft Word แจ้งไฟล์เสีย (`unreadable content`) — ให้ใช้ `python-docx` (`OxmlElement`) หรือ `lxml.etree` ที่รักษา Namespace Map เดิมเท่านั้น
- **QA ก่อนส่งมอบไฟล์ `.docx`**:
  1. รัน `unzip -t <file.docx>` ต้องไม่มีข้อผิดพลาด
  2. ตรวจ XML ทุกพาร์ทว่าไม่มี `w:rFonts`, `w:cs`, `w:noProof`, `w:lang` ซ้ำเกิน 1 ตัวใน `w:rPr` เดียวกัน และทุก Prefix ใน `mc:Ignorable` ถูกประกาศใน Namespace Map ครบถ้วน
