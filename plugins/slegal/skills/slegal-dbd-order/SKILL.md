# สั่งคัดถ่ายเอกสาร DBD e-Service และติดตามดาวน์โหลด (`slegal-dbd-order`)

สกิลมาตรฐานของสำนักงานสำหรับงาน **กรมพัฒนาธุรกิจการค้า (DBD)** ผ่าน **S-Legal MCP** (`slegal_dbd_order_*`) ตั้งแต่ตรวจสอบข้อมูลนิติบุคคล ออกใบ Pay-in / QR Code ให้ผู้มีอำนาจชำระเงิน จนถึงดาวน์โหลด e-Certificate PDF และตั้งเบิกค่าใช้จ่ายคืนผู้สำรองจ่าย

---

## กฎเหล็กและเส้นแดง (Non-Negotiable Rules)

1. **ห้ามชำระเงินเองเด็ดขาด (Red Line):** ผู้ช่วยมีหน้าที่สร้างคำขอคัดถ่ายและส่ง **ยอดเงิน ใบ Pay-in PDF และรูป QR Code** ให้ผู้มีอำนาจชำระเงินด้วยตนเองเท่านั้น
2. **ห้ามแก้หรือบายพาส CAPTCHA/OTP:** หากสถานะคำขอแสดงว่าต้องรอผู้ใช้งานยืนยันตัวตน (`waiting_human_auth`) ให้หยุดทันทีและแจ้งผู้มีอำนาจดำเนินการเอง ห้ามใช้สคริปต์บายพาสเด็ดขาด
3. **รักษาความลับ Credential:** ห้ามพิมพ์ค่า `slk_...` API Key หรือรหัสผ่านใด ๆ ลงในแชต ไฟล์งาน หรือบันทึกใด ๆ
4. **คงลายเซ็นดิจิทัล PKCS#7 ของหนังสือรับรอง:** ห้ามแปลงหรือเขียนทับไฟล์ e-Certificate PDF ต้นฉบับที่ดาวน์โหลดจาก DBD เพื่อรักษาความสมบูรณ์ทางกฎหมายของลายเซ็นอิเล็กทรอนิกส์
5. **นโยบายชื่อในใบเสร็จรับเงิน:**
   - **กรณีผูกสำนวนคดี (`caseId`):** ระบบออกใบเสร็จในนาม **ลูกความเจ้าของสำนวน** (`case_client`) เป็นค่าเริ่มต้น
   - **กรณีไม่ผูกสำนวนคดี:** ระบบออกใบเสร็จในนาม **นิติบุคคลของสำนักงานตามค่าเริ่มต้นที่ตั้งไว้** (`office_default`) เว้นแต่ผู้ใช้ระบุ `receiptPayerName` เป็นอย่างอื่น
6. **ห้ามเดาเลขนิติบุคคล 13 หลักหรือชื่อบริษัท:** หากผู้ใช้ระบุเพียงชื่อย่อหรือชื่อไม่ครบ ให้ตรวจสอบเลขทะเบียนนิติบุคคล 13 หลักและชื่อเต็มทางการจากข้อมูลในสำนวน (`slegal_case_intake_preflight` / `slegal_case_parties_get`) หรือเอกสารรับรองที่มีอยู่ก่อนสั่งคัดถ่ายเสมอ

---

## ขั้นตอนการทำงานมาตรฐาน (End-to-End Workflow)

### ขั้นที่ 1: ยืนยันข้อมูลนิติบุคคลและแพ็กเกจเอกสาร
- ตรวจชื่อนิติบุคคลเต็ม เลขทะเบียน 13 หลัก ประเภทเอกสาร (`packageCode`) และการผูกสำนวนคดี (`caseId` หรือค้นหาจาก `blackCaseNo`) ให้ชัดเจนก่อนสั่ง:
  - `cert_current` — หนังสือรับรองนิติบุคคล (รายการปัจจุบัน) · ค่าธรรมเนียมประมาณ `200` บาท
  - `boj5_latest` — บัญชีรายชื่อผู้ถือหุ้น บอจ.5 (ล่าสุด) · ค่าธรรมเนียมประมาณ `100` บาท
  - `financial_latest` — งบการเงิน (ล่าสุด) · ค่าธรรมเนียมประมาณ `200` บาท
  - `reg_incorporation` — สำเนาเอกสารจดทะเบียน (จัดตั้ง) · ค่าธรรมเนียมประมาณ `200` บาท
  - `reg_latest` — สำเนาเอกสารจดทะเบียน (ล่าสุด) · ค่าธรรมเนียมประมาณ `200` บาท
  - `cert_and_boj5` — หนังสือรับรองนิติบุคคล + บอจ.5 (ล่าสุด) · ค่าธรรมเนียมประมาณ `300` บาท

### ขั้นที่ 2: สั่งคัดถ่ายเอกสารผ่าน S-Legal MCP (`slegal_dbd_order_create`)
- เรียกเครื่องมือ MCP **`slegal_dbd_order_create`** โดยรองรับทั้ง:
  - สั่งรายบริษัท (ระบุ `searchQuery` / `juristicId` + `packageCode`)
  - สั่งเป็นชุดสูงสุด `15` บริษัทพร้อมกันผ่าน `companies[]`
  - สั่งคัดคู่ความนิติบุคคลทั้งหมดในสำนวนผ่าน `caseId` + `allCaseJuristics: true`
- ระบบจะส่งคำขอเข้าคิวให้ Worker เบื้องหลังของ S-Legal เข้าดำเนินการที่ระบบ DBD e-Service อัตโนมัติ

### ขั้นที่ 3: ส่งรายการจ่ายเงิน / ใบ Pay-in / QR Code ให้ผู้มีอำนาจ (`slegal_dbd_order_list`)
- ตรวจสอบสถานะคำขอด้วย **`slegal_dbd_order_list`** จนสถานะเปลี่ยนเป็น **`waiting_payment`**
- ส่งสรุปรายการจ่ายเงินให้ผู้มีอำนาจอย่างชัดเจน ประกอบด้วย:
  1. เลขคำขอ (`orderNo`) และชื่อบริษัท/ประเภทเอกสาร
  2. ยอดค่าธรรมเนียมจริงที่ต้องชำระ (บาท) และวัน-เวลาหมดอายุของใบ Pay-in
  3. ลิงก์ **รูป QR Code** และ **ใบ Pay-in PDF** (จากผล `slegal_dbd_order_list`)
- **หยุดรอผู้มีอำนาจชำระเงินและแจ้งยืนยัน** (ห้ามกดยืนยันชำระเงินก่อนได้รับแจ้งว่าชำระแล้ว)
- หากผู้ใช้ต้องการยกเลิกคำขอที่ยังไม่จ่ายเงิน ให้เรียก **`slegal_dbd_order_cancel`**

### ขั้นที่ 4: ยืนยันชำระเงิน → ตรวจและดาวน์โหลดเอกสารหลังจ่ายเงิน (`slegal_dbd_order_confirm_paid`)
- เมื่อผู้มีอำนาจแจ้งว่าชำระเงินแล้ว (หรือส่งสลิปโอนเงินมา):
  1. เรียกเครื่องมือ MCP **`slegal_dbd_order_confirm_paid`** พร้อมเลขคำขอ (และข้อมูลอ้างอิงการชำระเงินถ้ามี) เพื่อสั่งให้ระบบตรวจสอบสถานะการชำระเงินบน DBD e-Service และดาวน์โหลดไฟล์จริงอัตโนมัติ
  2. ตรวจสถานะด้วย **`slegal_dbd_order_list`** จนเปลี่ยนเป็น **`completed`**
  3. ยืนยันผลลัพธ์ที่ได้รับจริงครบทุกส่วน:
     - **หนังสือรับรองอิเล็กทรอนิกส์ (e-Certificate PDF)** หรือเอกสารที่สั่ง (คงลายเซ็นดิจิทัล PKCS#7)
     - **ใบเสร็จรับเงินกรมพัฒนาธุรกิจการค้า (Official Receipt PDF)**
     - **ใบตั้งเบิกค่าใช้จ่าย (`EC...`)** ที่ระบบสร้างอัตโนมัติคืนผู้สำรองจ่าย (หากมี)
  4. แจ้งลิงก์หรือสถานะการแนบไฟล์เข้าสำนวนใน S-Legal ให้ผู้ใช้ทราบครบถ้วน

---

## การดูแลเมื่อคำขอค้างสถานะ
- หากคำขอค้างสถานะ `queued` นานผิดปกติในเวลาทำการของ DBD ให้ตรวจรายละเอียดล่าสุดผ่าน `slegal_dbd_order_list` และแจ้งผู้ดูแลระบบ S-Legal ตรวจสอบ Worker เบื้องหลัง
- หากค้าง `waiting_human_auth` (ติด CAPTCHA/OTP) ให้แจ้งผู้มีอำนาจทราบตามจริงทันทีโดยไม่พยายามบายพาส
