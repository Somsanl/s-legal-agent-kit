# S-Legal Workspace Plugin (`v1.1.0`)

ชุดสกิลและเครื่องมือเชื่อมต่อ **S-Legal** ผ่าน MCP สำหรับทีมทนายความและทีมบัญชี (**Live บน Production ครบ `95` เครื่องมือ** = `36` งานกฎหมาย + `57` บัญชี/วางบิล/ภาษี + `2` ระบบ):

1. **`slegal-case-intake`**: เปิดและอัปเดตแฟ้มงานใน `Cases` ที่เดียวจบ (ทั้งคดีขึ้นศาลและโปรเจกต์ที่ปรึกษา/ร่างสัญญา/โนติส/จดทะเบียนธุรกิจ), ตรวจ Pre-Flight 4 จุด, จัดการคู่ความตามมาตรฐานศาลไทย และออกเอกสารแบบพิมพ์ศาล `.docx`
2. **`slegal-work-tracker`**: **Live MCP (`36` เครื่องมืองานกฎหมาย)** — ตรวจคิว `งานที่ต้องติดตาม`, ภาพรวมสำนวนครบใบเดียว (`slegal_case_snapshot_get` พร้อม QT Fee Privacy Gate), ตั้ง/แก้ไข/ย้ายแท็บงาน (`slegal_task_edit`), ยกเลิกคำร้อง soft-cancel (`slegal_filing_cancel`), ลงนัดศาลและบันทึกผลหลังนัดแบบ Atomic (`slegal_hearing_record_outcome`), อัปเดตอุทธรณ์/ฎีกา ป.พ.พ. ม.193/8, ค้นค่านำหมาย 262 ศาล, อัปโหลด/ดูเอกสารคดี, และสมุดเบอร์โทร
3. **`slegal-dbd-order`**: ค้นข้อมูลนิติบุคคลและสั่งคัดเอกสาร DBD e-Service (หนังสือรับรอง, บอจ.5, งบการเงิน) ส่งใบ Pay-in/QR ให้ผู้มีอำนาจชำระเงิน และดาวน์โหลด e-Certificate เข้าระบบ
4. **`thai-legal-drafting`**: มาตรฐานร่างคำฟ้องแพ่ง คำร้องศาล 3 ส่วน การพิสูจน์อักษรภาษาไทยทางการ และการตั้งค่าไฟล์ Word (`TH SarabunPSK 15 pt`, `<w:cs/>`, `noProof`)
5. **`slegal-billing-ops`**: **Live MCP (`23` เครื่องมือ)** — ออกใบเสนอราคา (`QT`/`MBA`), บันทึกผลอนุมัติลูกค้า, ออก/แก้ไขใบแจ้งหนี้ (`INV` รวมถึงงานที่ปรึกษารายเดือน), บันทึกค่าใช้จ่ายสำนวน, และตั้งเบิกค่าใช้จ่ายพนักงาน (`EC`)
6. **`slegal-accounting-ops`**: **Live MCP (`34` เครื่องมือ: `22 READ + 12 Safe Draft/Proof/Append`)** พร้อม **7 Red-Line Locks** — `GL`/งบทดลอง/ปิดงวด, `RC` & PDF, `AP`, `PV` & สลิปจ่าย (`ordinary + vendor`), Statement & กระทบยอด, `50 ทวิ / ภ.ง.ด.3-53` (`SECTION_40_6` 3% vs `SECTION_40_2`), และค่าตอบแทน/ECP/วางบิล EXP/OMEC (**READ ONLY** เฉพาะสิทธิ์ `partner-ledger.manage`)
