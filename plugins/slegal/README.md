# S-Legal Workspace Plugin

ชุดสกิลและเครื่องมือเชื่อมต่อ **S-Legal** ผ่าน MCP สำหรับทีมทนายความและทีมบัญชี (**Phase-1 Live: `54` เครื่องมือ** = `29` งานกฎหมาย + `23` บัญชี/วางบิล/ตั้งเบิก + `2` ระบบ):

1. **`slegal-case-intake`**: เปิดและอัปเดตแฟ้มงานใน `Cases` ที่เดียวจบ (ทั้งคดีขึ้นศาลและโปรเจกต์ที่ปรึกษา/ร่างสัญญา/โนติส/จดทะเบียนธุรกิจ), ตรวจ Pre-Flight 4 จุด, จัดการคู่ความตามมาตรฐานศาลไทย และออกเอกสารแบบพิมพ์ศาล `.docx`
2. **`slegal-work-tracker`**: ตรวจคิว `งานที่ต้องติดตาม` (`/follow-up`), ตั้งงาน/อัปเดตผล/แก้ไขงาน/ย้ายแท็บ (`slegal_task_edit`), ติดตามคำสั่งศาล, ลงวันนัดศาลพร้อมงานเตรียมคดีอัตโนมัติ, อุทธรณ์/ฎีกา และสมุดเบอร์โทร (รวมแนวทาง Phase-2 Planned 7 เครื่องมือ)
3. **`slegal-dbd-order`**: ค้นข้อมูลนิติบุคคลและสั่งคัดเอกสาร DBD e-Service (หนังสือรับรอง, บอจ.5, งบการเงิน) ส่งใบ Pay-in/QR ให้ผู้มีอำนาจชำระเงิน และดาวน์โหลด e-Certificate เข้าระบบ
4. **`thai-legal-drafting`**: มาตรฐานร่างคำฟ้องแพ่ง คำร้องศาล 3 ส่วน การพิสูจน์อักษรภาษาไทยทางการ และการตั้งค่าไฟล์ Word (`TH SarabunPSK 15 pt`, `<w:cs/>`, `noProof`)
5. **`slegal-billing-ops`**: **Live MCP วันนี้ (`23` เครื่องมือ)** — ออกใบเสนอราคา (`QT`/`MBA`), บันทึกผลอนุมัติลูกค้า, ออก/แก้ไขใบแจ้งหนี้ (`INV` รวมถึงงานที่ปรึกษารายเดือน), บันทึกค่าใช้จ่ายสำนวน, และตั้งเบิกค่าใช้จ่ายพนักงาน (`EC`)
6. **`slegal-accounting-ops`**: **คู่มือหน้าเว็บ + แผน Phase-2 MCP (`7` กลุ่ม `34` เครื่องมือ: `22 READ + 12 Safe Draft/Proof/Append`)** พร้อม **7 Red-Line Locks** — `GL`/งบทดลอง/ปิดงวด, `RC` & PDF, `AP`, `PV` & สลิปจ่าย, Statement & กระทบยอด, `50 ทวิ / ภ.ง.ด.3-53` (`SECTION_40_6` 3% vs `SECTION_40_2`), และค่าตอบแทน/ECP/วางบิล EXP/OMEC
