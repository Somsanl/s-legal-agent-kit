# Security Model & Safe Operation (`s-legal-agent-kit`)

## 1. ทำไม Public Repository นี้จึงปลอดภัย 100%

Repository `Somsanl/s-legal-agent-kit` เผยแพร่เฉพาะ:
- สกิล กฎการทำงาน (`AGENTS.md`) และเทมเพลตตัวอย่างสังเคราะห์
- สคริปต์ติดตั้ง (`install-windows.ps1`, `install-mac.sh`) และตัวเชื่อม MCP มาตรฐาน (`mcp/bridge.py`, `mcp/run-slegal-mcp.py`)

**ไม่มีการเก็บข้อมูลต่อไปนี้ใน Repository โดยเด็ดขาด**:
- Production host URL จริง, API Keys, รหัสผ่าน, Tokens, หรือไฟล์ `.env`
- ข้อมูลส่วนตัวลูกความ ชื่อลูกความจริง เลขคดีจริง เลขบัตรประชาชน 13 หลัก เบอร์โทรศัพท์ หรืออีเมลจริง
- ที่อยู่เซิร์ฟเวอร์ภายใน (Private IP / VPN / Localhost database ports)

---

## 2. การจัดเก็บและปกป้อง Endpoint และ API Key ส่วนตัว

1. **อ่านค่าจากไฟล์บนเครื่องผู้ใช้เท่านั้น**:
   - `bridge.py` และ `run-slegal-mcp.py` อ่าน URL ปลายทางจาก **`~/.slegal/mcp/endpoint`** (แปลง `https://host` -> `https://host/api/mcp` อัตโนมัติ และ fail-closed ทันทีหากไฟล์หายหรือยังเป็น `example.com`)
   - อ่าน API Key จาก **`~/.slegal/mcp/api_key`** เพียงแห่งเดียว (ไม่อ่านจากอาร์กิวเมนต์คำสั่ง และไม่ใช้ `SLEGAL_API_KEY` environment variable)
2. **การป้องกันไฟล์ระดับระบบปฏิบัติการ**:
   - **Windows**: ตัวติดตั้งกำหนดสิทธิ์ NTFS ด้วย `icacls` ให้เข้าถึงได้เฉพาะเจ้าของบัญชีปัจจุบันเท่านั้น (`/inheritance:r`)
   - **macOS / Linux**: ตัวติดตั้งกำหนดสิทธิ์โฟลเดอร์ `700` และไฟล์ `600` (`chmod 600 ~/.slegal/mcp/api_key`) และ `bridge.py` จะปฏิเสธการอ่านทันทีหากพบว่าเป็น Symlink หรือขนาดเกิน 512 ไบต์
3. **ห้ามเปิดเผยคีย์ในแชตหรือไฟล์งาน**: กฎใน `plugins/slegal/rules/AGENTS.md` ห้ามไม่ให้ AI พิมพ์ ส่งต่อ หรือบันทึกคีย์ `slk_...` ลงในคำสั่ง ข้อความตอบกลับ หรือไฟล์ในโปรเจกต์

## 3. การเพิกถอนและเปลี่ยน API Key (Key Rotation)

หากสงสัยว่า API Key รั่วไหล หรือมีพนักงานลาออก/เปลี่ยนเครื่อง:
1. ผู้มีสิทธิ์ดูแลระบบหรือเจ้าของคีย์เข้าหน้า **ตั้งค่า > Integrations** บนระบบ S-Legal ของท่าน แล้วกด **Revoke / เพิกถอน** คีย์เดิมทันที
2. สร้างคีย์ใหม่ (หากยังต้องใช้งาน)
3. ลบไฟล์ `~/.slegal/mcp/api_key` บนเครื่อง แล้วรันสคริปต์ติดตั้งซ้ำเพื่อกรอกคีย์ใหม่ผ่านช่องกรอกแบบซ่อนตัวอักษร

## 4. ขอบเขตความปลอดภัยของ MCP Bridge และงานบัญชี (7 Red-Line Locks)

- **ไม่ยิงซ้ำเมื่อ Timeout (`No Retry on Timeout`)**: หากการส่งคำขอไปยัง S-Legal เกิด Timeout สะพาน `bridge.py` จะรายงานให้ตรวจสอบสถานะด้วย `slegal_command_status` ก่อนเสมอ เพื่อป้องกันการสร้างใบแจ้งหนี้หรือเอกสารซ้ำซ้อน
- **HTTPS-Only + No Redirect**: ยอมรับการเชื่อมต่อเฉพาะ `https://` และปฏิเสธ HTTP Redirect เพื่อป้องกันการดักจับหรือเปลี่ยนเส้นทาง Token
- **7 Accounting Red-Line Locks**:
  1. ห้ามสร้าง/โพสต์/กลับรายการ GL หรือปิด/เปิดงวด
  2. ห้ามกลับรายการ `RC` ออกใบเสร็จอัตโนมัติ แก้ไขตัวลูกค้า (`mode="full"`) หรือส่งหาลูกค้าอัตโนมัติ
  3. ห้ามอนุมัติ `AP` โพสต์ `PV` GL ข้าม `bank_transaction_id` จริง แก้ไข `PV` ที่โพสต์แล้ว หรือโอนเงินธนาคาร
  4. ห้ามแก้ตาราง `bank_transactions` จริง หรือยืนยันกระทบยอดธนาคารอัตโนมัติ
  5. ห้ามออก/ยกเลิก `50 ทวิ` จริง ยืนยัน `taxFormConfirmed=true` หรือยื่น/ชำระภาษีกรมสรรพากรเอง
  6. `OMEC` / `Partner Ledger` เป็น READ ONLY ห้ามอนุมัติ `COMP` ห้ามออก `INV` จริงสำหรับ `EXP` และห้ามสั่งโอน K BIZ
  7. บังคับ `actorId` จริง, `idempotencyKey`, `audit_logs`, RBAC และงวดบัญชีเปิด `Asia/Bangkok` ทุกคำสั่ง
